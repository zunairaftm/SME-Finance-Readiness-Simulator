# One-Page Project Brief

## SME Finance Readiness & Improvement Simulator

**Type:** Applied finance / financial modelling / decision-support prototype

### Problem
SME financing readiness is broader than profitability or leverage alone. Businesses may have reasonable financial performance but weak documentation, inconsistent cash-flow monitoring, limited planning, or insufficient visibility into repayment capacity.

### Solution
I designed a transparent 100-point prototype that combines five dimensions:

- Financial health — 25%
- Cash-flow management — 20%
- Financial records & transparency — 20%
- Debt & repayment capacity — 20%
- Financial planning — 15%

The model produces a readiness score, classification, diagnostics, management recommendations and a What-If improvement simulation.

### Technical contribution
The prototype was implemented as an interactive Excel-based decision-support system with:

- linked financial calculations
- rule-based scoring
- management-practice diagnostics
- prioritized recommendations
- scenario analysis
- dashboard visualization
- quality-control and edge-case testing

### Research contribution
The project separates **financial condition** from **finance readiness**, providing a framework that can later be empirically tested using real SME observations.

### Validation roadmap
The next research stage would test:

- reliability of management-practice indicators
- factor structure
- empirical weighting
- sensitivity to threshold choices
- predictive validity against financing outcomes

### Key limitation
The current weights and thresholds are transparent prototype choices and have not been statistically validated. The model should therefore not be used for actual lending decisions.

### Portfolio value
The project demonstrates applied finance, financial modelling, spreadsheet engineering, scenario analysis, research design and evidence-informed decision-support development.
